# Premium V3 Upgrade Notes

This release adds:

- Premium homepage with a featured house-design showcase
- Modern admin sidebar, dashboard and login screen
- Scrollable admin navigation for smaller displays
- Fullscreen project gallery lightbox and related projects
- Expanded sample project galleries and two additional projects
- Floating desktop contact dock
- Mobile Call, WhatsApp and Quotation bar
- Header Call Now action
- Protected bundled image library

For an existing installation, replace the project files and import `database_patch_v2_premium.sql` once.
